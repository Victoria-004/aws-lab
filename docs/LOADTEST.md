# Навантажувальне тестування

## Сценарій

Скрипт `loadtest/locustfile.py`. Кожен користувач у циклі виконує 1 запис і 9 читань:

1. `POST /districts` — створення району;
2. `GET /districts/{id}` — щойно створений район;
3. `GET /districts` — список районів (3 рази за цикл);
4. `GET /districts/{id}` — випадковий район (3 рази за цикл);
5. `GET /districts/{id}/firedepartments` — пожежні частини району (2 рази за цикл).

Між кроками пауза 0,5–1,5 с. Перед тестом скрипт видаляє райони, створені попередніми прогонами.

## Параметри

| Фаза | Тривалість | Користувачі |
|---|---|---|
| Наростання | 3 хв | 0 → 30 |
| Стале навантаження | 5 хв | 30 |
| Спад | 2 хв | 30 → 0 |

N = 30: при такій кількості користувачів на одну задачу припадає понад 50 запитів за хвилину, і масштабування спрацьовує.

## Команда запуску

```powershell
locust --config loadtest/locust.conf --csv docs/loadtest_nocache
```
